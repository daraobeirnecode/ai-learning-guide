# AI Learning Guide

A build-led curriculum for progressing from complete beginner to an AI engineer, operator and AI-services provider.

## Start here

**[Open the Master Learning Guide](guide/MASTER_LEARNING_GUIDE.md)**

The repository includes:

- a five-stage, novice-to-expert curriculum;
- LLM, prompting, context, RAG, agent-loop and loop-engineering foundations;
- Claude Code, Codex and Hermes Agent operating models;
- skills, plugins, hooks, MCP, subagents and supply-chain safety;
- databases, n8n, infrastructure, observability, GIS/spatial AI and production operations;
- commercialization, paid-pilot and managed-service patterns;
- **97 directly linked source routes** under `sources/`: 66 sanitized educational copies, 28 privacy stubs and 3 third-party source stubs.

See [SOURCE_INDEX.md](SOURCE_INDEX.md) for every bundled source.

## Public-export boundaries

This repository is a sanitized educational export of private Obsidian knowledge bases.

- Credentials, private network details, personal email addresses and workstation paths are redacted.
- Third-party social/article captures are source stubs rather than copied prose.
- Architecture and maturity statements are educational snapshots, not proof that any system is currently deployed.
- Production writes, external messaging, regulated decisions and professional GIS/engineering/legal judgments require explicit authorization and accountable human review.
- Vendor behavior changes quickly; the master guide links to current first-party documentation for volatile commands and configuration.

## How to use it

1. Read the master guide in order.
2. Complete each practice artifact rather than reading passively.
3. Use the bundled notes when you need depth.
4. Record tests, evidence, failures and recovery steps.
5. Prefer the least-agentic system that reliably solves the problem.

## Installation safety

Never pipe a remote installer directly into a shell. Download it from the vendor's first-party domain, inspect the complete file, verify a pinned version or published checksum when available, and only then execute it with the minimum required privileges.
